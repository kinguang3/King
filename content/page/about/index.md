Hi, I'm King 👋

一名软件工程专业的学生，热爱编程，也热衷于将想法变成现实。

目前主要专注于 **Python 后端开发与 AI 应用开发**，探索 FastAPI、数据库、系统设计以及 AI Agent 等技术。同时，我也涉足全栈 Web 开发，并拥有使用 **Godot 制作游戏的实践经验**。相比单纯学习技术，我更享受从零构建一个项目、解决开发中的问题，并逐步理解其背后原理的过程。

我相信，代码不只是实现功能的工具，也是一种创造的方式。无论是构建一个 Web 应用、探索 AI 的可能性，还是在游戏世界里实现自己的想象，我都希望通过不断实践，让想法真正落地。

这个博客记录我的技术学习、项目实践、开发笔记与游戏制作历程，也记录我在探索软件开发这条路上的思考与成长。

**Build with curiosity. Create with passion. Keep exploring.**
